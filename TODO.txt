HOW TO RUN IT
-------------
- API for a phone:  cd backend ; php artisan serve --host=0.0.0.0 --port=8000
- App:              cd mobile ; npx expo start
- Mobile tests:     cd mobile ; npm test
- Live API test:    cd mobile ; ECHO_E2E_API=http://127.0.0.1:8000/api npx jest src/test-utils/live-api
- Backend tests:    cd backend ; php artisan test
- API URL config:   mobile/.env.example (dev finds your computer by itself; staging/production need https URLs)
